# Portion 911 | The Porsche 911 Enthusiast Chronicles

A cinematic, responsive automotive editorial and enthusiast experience celebrating the timeless silhouette, rear-engine heritage, and engineering mastery of the **Porsche 911**.

![Porsche 911 Banner](https://images.unsplash.com/photo-1503376780353-7e6692767b70?auto=format&fit=crop&w=1920&q=80)

---

## 🌟 Overview

**Portion 911** is an independent enthusiast tribute built with pure HTML5, CSS3, and vanilla JavaScript (no frameworks or dependencies). It is designed with a dark, cinematic aesthetic—combining obsidian blacks, graphite surfaces, cream typography, and iconic Porsche Guards Red accents.

---

## ✨ Features

- **Atmospheric Hero:** Full-screen experience with Ken Burns slow-pan visuals, telemetry counters, and an interactive **Web Audio API** engine sound synthesizer that simulates the high-rev roar of a flat-six boxer engine without external audio files.
- **Interactive 911 Legacy (Timeline):** Explores 8 landmark eras (1964 Original 911, 1973 Carrera RS, 1989 964, 1994 993, 1998 996, 2004 997, 2011 991, and 2019 992) with dynamic spec cards, historical milestones, and smooth transitions.
- **Featured Model Dossiers:** Interactive showcase for 911 Carrera, Carrera GTS, Turbo S, GT3, and Dakar with deep-dive technical modal sheets.
- **Performance, Perfected:** Animated telemetry stats counting up on scroll (Intersection Observer) and an interactive **Flat-Six Boxer Engine Blueprint (SVG)** with animated reciprocating pistons and technical anatomy hotspots.
- **Dream 911 Configurator:** Dynamic specification builder featuring real-time SVG silhouette rendering, 6 authentic exterior paint lacquers, alloy wheel packages, interior materials, performance equipment packs, live price computation, and a build sheet confirmation dossier.
- **Visual Archive & Lightbox:** Masonry-style gallery with category filtering (All, Heritage, Track, Road, Detail) and a full-featured keyboard-accessible modal lightbox (`Escape` to close, arrow keys to navigate).
- **Enthusiast Creed & Newsletter:** Atmospheric Ferry Porsche creed and a validated subscription form for monthly editorial dispatches.

## 🚀 Live Deployment on GitHub Pages

This project is 100% static and ready for instant, zero-configuration hosting on **GitHub Pages**:

1. Create a new repository on GitHub named `porsche-911` (or any name you prefer).
2. Push or upload `index.html`, `styles.css`, and `script.js`.
3. Go to repository **Settings** → **Pages** (under the "Code and automation" sidebar).
4. Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)` folder.
5. Click **Save**. Within 1–2 minutes, your website will be live at:
   ```
   https://<your-username>.github.io/porsche-911/
   ```

## 💻 Local Development

No build tools or servers required. Simply open `index.html` in any modern web browser:

```bash
# Windows PowerShell / Command Prompt
start index.html

# Or with Python local server
python -m http.server 8000
```
